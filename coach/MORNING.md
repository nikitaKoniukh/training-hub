# Утренняя проверка (05:10, тренировка в 05:30)

Цель: за ~10 минут проверить новую ночь и при необходимости заменить сегодняшнюю тренировку.
Никита к 05:20 должен получить ответ и успеть синхронизировать часы. Коротко, без анализа недели.
Пороги, зоны и формат тренировок — из `coach/COACH.md` (прочитай разделы «Атлет», «План» и пункт 5).

GitHub: только git и `gh api` (REST). `gh workflow/run/pr` не работают.

## Шаги

1. `git pull`. Сегодня = дата по Asia/Jerusalem.
2. Запроси синк: `date -Iseconds > requests/sync && git add requests/sync && git commit -m "morning: request sync" && git push`.
   Каждые 30 с `git pull`, пока в `data/daily/<сегодня>.json` не обновится `syncedAt`.
   Новая ночь пришла, если `sleep.end` — сегодняшнее утро и есть `hrv.lastNightAvg`.
   Если синк прошёл, а ночи ещё нет (часы не синхронизировались с телефоном) — повтори запрос синка один раз
   через 3 минуты. Дедлайн — 05:20: дальше не ждать.
3. Сегодняшняя тренировка = `workouts/<сегодня>.json` (если есть) + вчерашний отчёт `reports/<вчера>.md`.
   Нет тренировки (отдых/силовая) → проверь только восстановление и сообщи.
4. Оцени новую ночь по красным флагам из COACH.md (HRV, сон, RHR, утренний Body Battery, ночной стресс,
   readiness/recoveryTime) + свежие записи `feedback.md`.
   - 0 флагов → тренировка без изменений.
   - 1 флаг → лёгкий день без изменений; ключевая — объём интенсива −30 % (меньше повторов/короче блок МТ).
   - 2+ флага → ключевая заменяется на E 40–50 мин (HR ≤ 145) или отдых; лёгкий день — сократить на 30 %.
   - Нет данных ночи к 05:20 → ничего не меняй.
   - В `feedback.md` есть «тренировка <сегодня>: попросил ЛЕГЧЕ» → это минимум 1 флаг (снизь), даже при зелёных данных.
     «ОТМЕНИЛ» → тренировки нет, ничего не пушь, просто подтверди восстановление.
5. Если меняешь: перезапиши `workouts/<сегодня>.json`, проверь `python -m hub.workout_builder workouts/<сегодня>.json`,
   коммит + push в `main` (push-workout заменит тренировку в календаре Garmin). Через ~2 мин `git pull`
   и проверь новую запись в `logs/pushed.jsonl`.
   Ключевую, снятую утром, вечерний тренер переставит — это его решение, не твоё.
6. Допиши в `reports/<сегодня>.md` (создай, если нет) раздел `## Утро 05:10` — 2–3 строки: флаги и решение. Коммит + push.
7. Итог — в Telegram и в SendUserMessage, одинаковый текст, максимум 2 строки, первым словом решение.
   Telegram: `outbox/<YYYYMMDD-HHMM>-morning.json` = `{"text": "..."}` (без кнопок) + push в `main`.
   Сделай это сразу после решения, до записи отчёта — сообщение важнее отчёта.
   - `ОК — <тренировка> как запланировано. HRV 46, сон 7:20, BB 92.`
   - `ЗАМЕНИЛ — <новая тренировка>. Причина: <флаги>. Синхронизируй часы.`
   - `НЕТ ДАННЫХ — часы не синхронизировались. Делай <тренировка>, ориентируйся на самочувствие.`
   - Если замена не дошла до Garmin — `ЗАМЕНА НЕ ОТПРАВИЛАСЬ — сделай вместо <старой>: <новая словами>.`
